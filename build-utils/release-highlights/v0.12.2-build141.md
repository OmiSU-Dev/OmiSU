## Highlights

### Streaming setup (Settings → Streaming)
- **Platform cards** for Twitch, YouTube, and Kick — tap a destination to auto-fill the RTMP ingest URL.
- **Step-by-step help**, **Open stream settings** (creator dashboard in the browser), and **Paste stream key** from the clipboard.
- Manual server URL and stream key fields remain for custom RTMP.

### In-game streaming fixes
- Request **microphone permission** when needed for game-audio capture (Android requirement for playback capture).
- Use **mono audio capture** so stream start works reliably on more devices (including OnePlus).

### Security
- No baked-in or auto-merged Kick stream keys — users paste their own key in Settings → Streaming.
