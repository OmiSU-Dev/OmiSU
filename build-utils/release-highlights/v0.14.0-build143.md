## Highlights

### Android game streaming (alpha)
- **Live stream Play Store and sideloaded Android games** to Twitch, YouTube, or Kick using the same RTMP setup as embedded play.
- **Pre-launch prompt** when streaming is enabled: choose whether to go live when you start the game.
- **MediaProjection** flow after launch; pick **your game app** or entire screen when Android asks what to share (app-only often starts faster on some phones).
- **Experimental** banner in Settings → Streaming — previews and stability can vary by device; built-in emulator streaming remains the most reliable path.

### Streaming quality and uplink
- **Stream quality preset** in Settings (cycles target resolution/bitrate band).
- **Adaptive uplink bitrate** ramps from a conservative start toward your cap using live RTMP metrics (separate tuning for embedded vs Android games).
- **30 fps** for external Android capture to reduce ingest issues on Kick and similar platforms.
- **Game playback audio** capture mixed with mic when enabled (with microphone permission when required).

### Settings and Nordi UX
- **Streaming** section: platform cards, dashboard link, paste stream key, validation, and localized setup steps (from prior releases, now paired with Android-game streaming).
- **Power Menu** consolidates restart / shut down; retail hides separate **Exit** and **Tools** menu entries (Safe mode restores dev options).
- **Sleep tab**: display off via system sleep or accessibility lock; USB controllers stay powered until shut down.
- **Home app shortcuts** and default **HOME role** notes for retail launcher behavior.

### Reliability fixes (streaming path)
- Bind streaming service with **application context** so capture survives the consent activity finishing.
- External-play **encode resolution and bitrate caps** tuned for phone uplinks.
- Trace tags for diagnosing stream state, uplink ramp, and capture handoff (`logcat` friendly).
